# Shakeelah Khan — Developer Portfolio

Responsive developer portfolio website built with HTML, CSS and JavaScript.

## Preview locally
Open `index.html` in a browser, or run `python3 -m http.server 8000` from the repository root.

## Publish on GitHub Pages
Go to **Settings → Pages → Build and deployment → Deploy from a branch**. Choose **main** and **/(root)**, then save. Your site should be available at https://st10458151.github.io/developer-portfolio/ after deployment.

## Contents
- Introduction and career focus
- Skills and technologies
- Featured academic projects (summaries only; private source repositories are not linked)
- Swiss Hotel School Work-Integrated Learning experience
- Education, achievements and professional development
- LinkedIn, GitHub and email links

## Notes
The site is based on a CV and intentionally describes 2027 Honours as an application **pending** admission. The site does not include a backend, collect form submissions or show proprietary university project source. Contact links use email.

Review public-facing information before publishing.
