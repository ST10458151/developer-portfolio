## Getting started

**Option 1 — Open directly**

1. Clone the repository:
   ```bash
   git clone https://github.com/ST10458151/developer-portfolio.git
   ```
2. Open the `developer-portfolio` folder.
3. Double-click `index.html` to view the site in your browser.

**Option 2 — Run a local server**

```bash
cd developer-portfolio
python3 -m http.server 8000
```

Then visit **http://localhost:8000**.

## Deployment

This website is deployed through **GitHub Pages** from the `main` branch.

To set up Pages on a fork, open **Settings → Pages**, select **Deploy from a branch**, choose `main` and `/(root)`, and save. GitHub Pages will publish the static site after its deployment completes.
